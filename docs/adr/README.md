Index verified on 2026-10-11 against the ADR files (status lines and dated rollout blocks) and, where a fresher record exists outside the ADR, against the record each row names.

ADRs document **non-obvious** architectural decisions — the choices that would
surprise a new contributor or that an AI assistant might accidentally reverse.

## Status Values

- **Draft** — Written but not yet decided; includes precondition-only drafts
  (e.g. ADR-032) and in-flight review rounds (e.g. ADR-037). Annotate dated
  checkpoints, e.g. "Draft (round-3; amended 2026-09-05)".
- **Proposed** — Under discussion. Code may land before acceptance; the
  qualifier then says what landed and what is open (e.g. ADR-036, ADR-058).
- **Accepted** — Active decision. When implementation is partial, keep the
  status Accepted but record landed-vs-open items in a dated rollout-status
  block inside the ADR (see ADR-035).
- **Superseded** — Replaced by a newer ADR (link to successor), e.g. ADR-009,
  superseded per ADR-064 (gap row D-32); its own header still says Proposed.
- **Deprecated** — No longer relevant (no ADR carries this status today).

**Header line format** (normalised 2026-10-18, platform hardening plan H-11.7):
the ADR's first status line is `**Status:** <State> (<date>, <qualifier>)` —
plain bold label, no list bullet, block quote or `## Status` heading, the state
spelled as listed above. 37 records that used another form were rewritten on
that date (header line only; the text after the state is unchanged apart from
`—`, `·` or `→` separators becoming a parenthesis). One record keeps a
non-vocabulary state: the ADR-012 API annex
([012-assistant-api-v1-contract.md](012-assistant-api-v1-contract.md)) says
`Stable`, a contract maturity rather than a decision state; mapping it is the
maintainer's call. ADR-009's header still says Proposed (see its index row).

Parenthetical date/round qualifiers on the base status are part of the
convention — they keep "freshness" visible without minting new status names.
When a record outside the ADR (a gap-analysis row, the wave ledger) is fresher
than the ADR's own rollout block, the qualifier names that record.
