## Answer key (facilitators)

**Lab 1.4 RAG question:** *Which reference model, Moho depth and mantle
velocity do we use for a Kii Channel event, and when is a pick rejected?* —
**KRSO-1D v2** (rule RM-1), **Moho 28 km**, **mantle 7.9 km/s**, reject when
**|residual| > 2.5 s** (rule PQ-3). Sources: files 01 and 02.

Measured 2026-10-27 (Numba answer key unless noted):

| Data | Model | Mean residual | RMS |
|---|---|---|---|
| Real ISC picks (25 stations), 2 km grid | ak135 crust | −1.12 s | 1.32 s |
| Real ISC picks, 1 km grid | ak135 crust | −0.94 s | 1.14 s |
| Real ISC picks, 2 km grid | KRSO-1D v2 | +0.04 s | 0.46 s |
| Real ISC picks, best of 162 searched (2 km) | 5.7 / 6.5 / Moho 26 / 7.9 | 0.00 s | 0.44 s |
| Synthetic fallback (30 stations), 2 km | ak135 crust | −1.21 s | 1.38 s |
| Synthetic fallback, 1 km | KRSO-1D v2 (the true model) | −0.13 s | 0.17 s |
| Synthetic fallback, best of 162 searched (2 km) | 5.9 / 6.5 / Moho 26 / 7.9 | −0.05 s | 0.14 s |
| Synthetic fallback, Part 2 workflow (NumPy, 4 km, 54 s) | ak135 / best | −1.30 / −0.01 s | 1.48 / 0.21 s |

Our ak135 residuals for the real picks track the ISC's own ak135 residuals
(difference −0.36 s mean at 2 km, −0.18 s at 1 km: it halves with the grid
spacing). The invented KRSO-1D v2 happens to fit the real event almost as
well as the best searched model — a good closing point for Lab 1.4.

Teaching points: ak135 is about 1 s too slow along these paths (Pn); Moho
depth trades off against lower-crust velocity (several models within
0.02 s); on the 4 km workflow grid, Moho depths 2 km apart cannot be told
apart; even with the true model the residual is not zero (first-order
scheme + picking noise).
