# KRSO-1D v2 — 観測所の参照 P 波速度構造モデル

> チュートリアル教材。近畿地域地震観測所(KRSO)、そのモデル、本ファイルの
> 数値はすべて **R4 + UMRS チュートリアルのための架空のもの**です。どの言語
> モデルも知り得ない内容にしてあるため、Lab 1.4 の RAG オン/オフ比較で答えが
> はっきり分かれます。

## モデル

| 層 | 上端 (km) | 下端 (km) | P 波速度 (km/s) |
|---|---|---|---|
| 上部地殻 | 0 | 18 | 5.9 |
| 下部地殻 | 18 | 28 | 6.7 |
| 最上部マントル | 28(モホ面) | — | 7.9 |

地殻中部の境界(コンラッド面)は **18 km**、**モホ面は 28 km** に固定する。
v2 では観測点の標高を無視し、観測点補正も適用しない。

## どのモデルを使うか(規則 RM-1)

- KRSO 観測網の範囲内(近畿、紀伊水道、四国東部)の地震と観測点:
  **KRSO-1D v2**。
- 震央距離 3° を超える経路:全球モデル **ak135**。
- 1 つの残差レポートの中でモデルを混在させない。

## 経緯

- **v1(2019 年)** はモホ面 32 km、マントル速度 8.0 km/s だった。
- **v2(2025 年)** では、紀伊水道の地震の再検討で Pn が系統的に早く到達する
  ことが分かったため(`03-event-review-notes.md` 参照)、モホ面を 28 km に
  浅くし、マントル速度を 7.9 km/s に下げた。
