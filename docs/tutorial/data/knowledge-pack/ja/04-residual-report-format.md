# 残差レポートの書式(規則 RR-2)

> チュートリアル教材。観測所のレポート書式は架空のものです。

残差レポートには、次の順に必ず含める:

1. **ヘッダ:** 地震(発生時刻 UTC、緯度、経度、深さ)、読み取りの出典
   (カタログ名と引用)、参照モデルの名前と版。
2. **表**(観測点ごとに 1 行):観測点コード、震央距離 (km)、相、観測走時
   (秒)、予測走時(秒)、残差(秒、観測 − 予測)、採用/棄却(PQ 規則とともに)。
3. **要約:** 採用観測点の数、平均残差、RMS 残差、Pg と Pn それぞれの平均残差。
4. **図:** 震央距離に対する走時 — 観測は点、モデルの予測は線。
5. **再現性の行:** 使ったソルバと格子間隔、およびレポートを再作成するコマンド。

読み取りの出典とモデルの版がないレポートは受理しない。
