# 再検討ノート — 紀伊水道の地震(内部資料、2025 年)

> チュートリアル教材:地震学の研究グループがカタログの隣に置いておく再検討
> ノートを模した架空のノートです。

## 確認したこと

紀伊水道の浅い地殻内地震について、地域の P 波読み取りの走時残差を、全球
モデル ak135 と自分たちのモデルで予測して比べた。

## 分かったこと

1. **ak135 はこの地域では遅すぎる。** クロスオーバー距離より遠くでは初動は
   Pn になり、Pn は ak135 に対して約 **1 秒早く** 到達する。ak135 の 35 km
   より薄い地殻と整合的である。
2. **トレードオフ。** モホ面の深さと下部地殻の速度は互いに打ち消し合い、
   いくつものモデルの組がほぼ同じくらい読み取りに合う。モホ面を 28 km に
   したのは、グループのレシーバ関数解析(内部報告 KRSO-RF-2024、この
   パックには含まれない)と合うためである。
3. **1 つの地震を過大に解釈しない。** 数十点の観測点を持つ 1 つの地震が
   決めるのは、その経路に沿った平均的な 1 次元モデルであり、3 次元構造では
   ない。

## 決定

2025-04-01 から **KRSO-1D v2**(ファイル 01)を採用する。2024 年分の残差
レポートはすべて v2 で再計算し、古いレポートには「v1」と明記する。
