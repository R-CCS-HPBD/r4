# 読み取り品質と採用の規程(PQ 規則 第 3 版)

> チュートリアル教材。観測所とその規則は架空のものです。

## 読み取りの等級

| 等級 | 立ち上がり | 時刻の不確かさ | 重み |
|---|---|---|---|
| A | 明瞭(インパルシブ) | ≤ 0.05 秒 | 1.0 |
| B | はっきり | ≤ 0.1 秒 | 0.5 |
| C | 緩やか(エマージェント) | ≤ 0.3 秒 | 0.25 |
| D | 疑わしい | > 0.3 秒 | 0(使わない) |

## 採用の規則

- **PQ-1** 観測点ごとに最初の P 波の読み取りだけを使う。
- **PQ-3** 参照モデル(`01-reference-model-krso-1d-v2.md`)に対する残差の
  絶対値が **2.5 秒** を超える読み取りは棄却する。棄却した数と理由を報告する。
- **PQ-5** Pn と付けた読み取りは震央距離 **140 km** より遠い場合だけ有効。
  それより近い「Pn」は付け直して再確認する。
- **PQ-7** 残差レポートには採用観測点が **8 点以上** 必要。満たない場合は
  *暫定* とする。

残差は常に **観測 − 予測**(正 = 遅れ)とする。
