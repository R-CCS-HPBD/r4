# R4 + UMRS — repo agent briefing

Loaded into the R4 agent's own prompt **inside this repo tree** with
AGENTS.md and CLAUDE.md (`r4/src/r4/briefing.py`: 4,000 chars per file, 8,000 in all).

**What this repo is.** An AI platform for working scientists: R4 (client:
console, agent harness, skills, sessions, research loop) + UMRS (server on
the cluster front-end: accounts, ZeroMQ/HTTP transports, durable jobs,
Slurm/k8s/Podman orchestration, models, knowledge spine, pgvector, MCP
registry) + the Scientific Catalog (portable knowledge bundle; the object
and `r4 catalog` exist, D-39 Partial as of 2026-10-18). Design: `docs/R4-UMRS-DESIGN.md`. Gaps: `docs/R4-UMRS-GAP-ANALYSIS-2026-09-22.md`.
Request path today: r4 → gateway (`/gw/*`, JWT) → UMRS → mini-RiVault; data
over ZeroMQ direct-TCP. Never reach vLLM, LiteLLM, S3 or Postgres directly.

**Multi-agent work** — author one team plan per phase (`team_plan_templates` → `team_plan_run`, skill `team_plans`, ADR-092) and read its result before the next; a null is unknown, never passed.

## Working rules

1. **Evidence before verdict** — re-run the failing command, read the file,
   grep the message; never re-assert a state.
2. **Never modify a gate to pass it** — refactor the flagged code; a
   threshold change is an architecture review (CONSTITUTION §5.2).
3. **Credential operations are never automatic** — stop and name the exact
   shell command for the user.
4. **Per-commit gates** — `bash scripts/ci-lint-local.sh` prints
   `ALL CHECKS PASSED` for every commit touching Python, not only the tip.
5. **Fix flakes, never tolerate them.**
6. **Full gate before "done"** on every edited file (plus Codacy where the
   maintainers' setup provides it).
7. **Fail-closed on safety, fail-degraded on user surface** — no wired
   `PermissionManager` means no tools; a missing config source means defaults.
8. **Reports match the code they describe** — strings, names, paths, command
   output verified at write time; stale reports carry a SUPERSEDED banner.
9. **Name the gap rows** (`D-nn`) a change advances; moving away from the
   design needs an ADR first.
